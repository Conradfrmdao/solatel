# Daybreak Terminal prop sources

These freely available assets are public domain under [Poly Haven's CC0 dedication](https://polyhaven.com/license). Authored geometry and PBR maps are preserved at 1K. Rebuild with `python scripts/fetch-terminal-props.py`; the game serves the packed local files and never calls the download API.

- [Metal Tool Chest](https://polyhaven.com/a/metal_tool_chest), John Hutcheson and Yann Kervran.
- [Old Military Crate](https://polyhaven.com/a/old_military_crate).
- [Fern 02](https://polyhaven.com/a/fern_02).
- [Industrial Wall Lamp](https://polyhaven.com/a/industrial_wall_lamp), Kuutti Siitonen.
- [Potted Plant 02](https://polyhaven.com/a/potted_plant_02).
- [Smooth Concrete Floor](https://polyhaven.com/a/smooth_concrete_floor), Dimitrios Savva. Floor maps use 2K.
